    Anomaly detection thresholds

    The 6 gait anomalies the public analyzer flags, and the ranges it uses to decide mild vs notable. Live rows update as new reference sessions are added; fixed rows come from the running gait literature or clinical convention. Detections that have left/right structure (overstriding, hip drop, knee valgus, arms crossing) flag each side independently and surface a side tag on the report.

    Anomaly Baseline / basis Mild Notable

    Live — derived from the reference dataset for the selected sex (median + MAD-based robust SD; one bad session can’t move the threshold). Fixed — a constant from the literature or clinical convention. Hip drop and knee valgus are sex-adjusted (+1° for female); arms crossing is the same for both sexes. No data — fewer than 5 reliable sessions for this metric, so the analyzer uses a fallback value.

    Frame-selection diagnostic

    Compares the detector's auto-picked frame against admin "Correct frame" labels. Numbers are stride-aware — running gait is cyclic, so a delta of one full step usually means the detector picked a different (still valid) stride, not a wrong event. We collapse the raw delta by an estimated stride period (~700ms) so only the within-stride miss counts. Hit = auto landed within 40 ms of the labeled correct frame's beat.

    Phase n Hit rate (≤40 ms) Within-stride bias Median miss Distribution (0 / 40 / 80 / 120+ ms off)
    Click “Run diagnostic” to analyze labels.

    Within-stride bias: + = detector picks LATER than the correct frame within a stride, − = detector picks EARLIER. Wrong-stride differences are folded into a within-stride delta first.  · Median miss: absolute within-stride distance in milliseconds.  · Outlier filter drops labels for any of: corrupt or weak pose (avg major-joint score < 0.40), phase/pose mismatch (e.g. L foot strike where R ankle is on the ground), within 0.20s of the video edge, or anchor-metric value > 3.5 MAD from same-phase cohort median. The summary breaks down how many fell out by reason.  · Label source: labels without a source were saved from esFormLab.
